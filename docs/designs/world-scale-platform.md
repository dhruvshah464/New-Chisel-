## Recommended Approach

Approved near-term: Approach A. Company shape: C. Ambition (not this week): B, slice by slice, only when a named paying pilot requires that slice.

Protect the wedge:

- Never host the customer's agent or model keys.
- Verdicts still come from the proxy record, not the agent's story.
- **Reviewer-facing verification is SHA-256 of the files listed in `manifest.json`.** Anyone recomputes those hashes with `aisec verify` or `site/verify.html`. That check does not need New Chisel, an account, or an HMAC key. HMAC-SHA256 in `signature.json` is only for *this desk* to refuse unsigned ingest. `key_id` is SHA-256 of the desk key. A stolen HMAC key is rotate-and-reissue; hashes still catch silent file edits. Sigstore is a later authenticity overlay, not the hash-check. The desk UI must not become an oracle: it displays verify's result, it does not replace it.
- `resisted_by=tools|model` stays a first-class field on product grounds (a model refuse is not a tool control).
- Authorization.yaml still required for `--target command`.
- Production and real data remain refused.

Near-term work (90 days, no named pilot required):

1. Distribution: PyPI `aisec` 0.1.0, GitHub Action on `dhruvshah464/New-Chisel-`, replace placeholder `you@example.com` on `site/index.html`, `legal/dpa.md`, and `aisec init` output with the founder contact once counsel names it.
2. Public real-model sample under `site/sample/` when a founder-owned API key exists.
3. Local desk stays loopback (`127.0.0.1`). No hosted control plane in this plan. No "trust center" product in this plan. No Docker image in this plan (loopback vs published ports is unresolved, so it is cut).

Parked until a named paying pilot's written scope requires it (later spec, not this doc):

- HTTP/SSE MCP proxy, on the **customer's machine**, wrapping their remote servers. It may see MCP stdio/HTTP traffic. It must not receive or log model API keys. If that cannot be guaranteed for a given pilot, refuse the pilot rather than host keys.
- Adapters for agents that do not take stdio `mcp.json`.
- Scenario corpus past the shipped 14 files.
- Sigstore authenticity overlay.
- Runtime gateway (stage-gates Stage 3). Explicit cut: independence vs enforcement. Enforcement is not this company.
- Marketplace.

Visual source of truth already shipped: local desk at `aisec serve` and `site/index.html`.
